\# Estructura del Prompt



Para desarrollar el proyecto R2 con apoyo de Inteligencia Artificial se utilizó una estructura de prompt organizada en seis partes.



\## 1. Rol



Se indica a la Inteligencia Artificial qué función debe cumplir.



Ejemplo:



Actúa como asistente de programación especializado en Kotlin y Programación Orientada a Objetos.



\## 2. Contexto



Se explica el escenario en el que se desarrolla el proyecto.



Ejemplo:



Estoy desarrollando un proyecto académico de un carrito de compras en Kotlin.



\## 3. Objetivo



Se indica claramente qué se desea obtener.



Ejemplo:



Necesito desarrollar una versión orientada a objetos del carrito de compras.



\## 4. Requisitos



Se especifican las características obligatorias del proyecto.



\- Abstracción.

\- Herencia.

\- Encapsulamiento.

\- Polimorfismo.

\- Uso de clases.

\- Ejecución mediante consola.

\- Código en Kotlin.



\## 5. Restricciones



Se indican las condiciones que debe respetar la solución.



\- Utilizar Kotlin.

\- Mantener nombres de clases y funciones claros.

\- No utilizar frameworks adicionales.

\- El código debe ser sencillo y fácil de explicar durante una sustentación.



\## 6. Formato de salida



Se solicita que la IA entregue código Kotlin organizado y una explicación de los conceptos de Programación Orientada a Objetos utilizados.
